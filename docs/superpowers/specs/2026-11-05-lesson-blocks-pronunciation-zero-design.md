# Комплексные упражнения и «Урок 0» — проект

## Замысел

Сделать обучение менее похожим на набор отдельных карточек: в Уроке 1 пользователь переводит связанный блок предложений, а в Уроке 0 системно учится читать и произносить французские звуки через эталонные слова, слоги и короткие фразы.

## Цели

- Перевести текущие 16 упражнений Урока 1 в несколько блоков по 5–7 строк.
- Проверять строку по Enter, не раскрывая правильный ответ при первой ошибке.
- После кнопки «Проверить всё» показать ответы и объяснения только для ошибочных строк.
- Повторять только ошибки; сохранить Boost для конкретного предложения.
- Добавить отдельный «Урок 0 · Звуки» с бесплатным TTS устройства и локальным прогрессом.
- Сохранить установку PWA, приватность прогресса и работу на GitHub Pages.

## Не делаем в этой версии

- Не записываем и не анализируем голос пользователя через микрофон: распознавание речи на iPhone нестабильно и создаёт лишний риск приватности.
- Не обещаем точное изолированное произношение фонем через системный TTS. Озвучиваем эталонные французские слова и слоги, где звук слышен в контексте.
- Не подключаем платный TTS и не размещаем API-ключи в браузере.
- Не копируем исходный PDF или его 73 страницы в публичный репозиторий.

## Подходы

### 1. Полностью заменить одиночные упражнения комплексными блоками — выбран

Урок 1 остаётся одним разделом, но показывает несколько предложений одновременно. Это наиболее близко к предоставленному примеру, тренирует удержание нескольких конструкций и не перегружает интерфейс дополнительными режимами.

### 2. Оставить одиночные упражнения и добавить отдельный режим «Комплекс»

Сохраняет оба формата, но создаёт лишний выбор и дублирование прогресса. Для первой версии не выбран.

### 3. Проверять каждую строку с немедленным показом ответа

Быстрее даёт подсказку, но снижает активное вспоминание. Не выбран: по Enter показываем только красный/зелёный статус, а ответы раскрываем после итоговой проверки.

## Урок 1: комплексные блоки

- 16 существующих заданий группируются в три тематических блока без изменения стабильных `id`.
- На экране одновременно 5–7 русских предложений или заданий и отдельное поле для каждого ответа.
- Enter проверяет текущую строку:
  - корректная строка становится зелёной;
  - некорректная становится красной;
  - правильный ответ и объяснение пока не показываются;
  - фокус переходит к следующей строке.
- «Проверить всё» проверяет заполненные строки и раскрывает правильный вариант с объяснением для каждой ошибки.
- После итоговой проверки кнопка «Исправить ошибки» оставляет только неверные строки. Правильные ответы не нужно вводить повторно.
- Boost принадлежит конкретной строке, а не всему блоку. Приоритетный блок выбирается по наличию Boost, затем по ошибкам, затем по обычному порядку.
- Счётчики остаются по отдельным предложениям: верно, повторить, Boost.
- Существующий локальный прогресс мигрирует без потери корректных попыток.

## Урок 0: звуки и чтение

В приложении появляется отдельный учебный раздел «Урок 0 · Звуки». Исходный PDF используется только как ориентир по последовательности тем. Публичные объяснения, примеры и упражнения создаются заново; исходный файл, изображения страниц и полный список примеров не публикуются.

Материал группируется в короткие модули:

1. Простые гласные и различия `a / i / o / u`.
2. `e / é / è / ê` и чтение в словах.
3. Согласные и соединение согласной с гласной в слоги.
4. Сочетания `ch / qu / gu` и группы согласных.
5. `ou / oi`.
6. Носовые сочетания `on / an / en / in / un`.
7. `au / eau / eu / œu / ui`.
8. Изменение звука в `c / ç / g / ge / gn / ph`.
9. Сложные сочетания `ill / ail / eil / ouil / tion`.
10. Непроизносимые окончания, включая глагольное `-ent`, и итоговое чтение.

Карточка звука содержит:

- буквенное сочетание и простое русское объяснение;
- одно главное эталонное слово с визуальным выделением сочетания;
- кнопку «Слушать» — системный французский голос произносит полное слово;
- 3–6 дополнительных слов и короткую строку для чтения;
- действия «Повторить» и «Получается»;
- локальное интервальное повторение и Boost на уровне звука.

Каждый модуль завершается `Bilan`: пользователь читает набор знакомых слов и короткую фразу, может прослушать эталон целиком и отметить результат самостоятельно.

## Навигация

Основные разделы PWA:

- «Карточки»;
- «Урок 0 · Звуки»;
- «Урок 1 · Перевод».

На iPhone они оформляются как компактный переключатель. Активный урок и локальный прогресс восстанавливаются после перезапуска приложения.

## Данные и приватность

- В GitHub Pages публикуются только оригинально составленные учебные данные приложения.
- Исходный PDF не копируется в репозиторий и не включается в service worker.
- Ответы, Boost, попытки и пользовательские карточки остаются в `localStorage` конкретного браузера.
- Публичная ссылка не содержит прогресс и личные данные.

## Проверка результата

- Автоматические тесты: Enter не раскрывает ответ, итоговая проверка раскрывает ошибки, повтор содержит только ошибки, Boost остаётся до ручного отключения, старый прогресс мигрирует.
- Статические PWA-тесты: новые модули входят в service worker, приватный PDF и секреты отсутствуют.
- Живая проверка GitHub Pages: блок на мобильной ширине, клавиатурный переход, итоговая проверка, повтор ошибок, TTS слова, сохранение после перезагрузки.
- Физический iPhone остаётся финальной пользовательской проверкой качества голоса и установки.
